# Automatización del Reporte Share Móviles

Genera los reportes de Móviles y Accesorios desde las fuentes privadas de Google Drive y publica `dist/` directamente en Cloudflare Pages.

Este repositorio contiene únicamente código de automatización y plantillas. No almacena bases Oracle, archivos CRUCES, listas de precios, salidas generadas ni credenciales.
